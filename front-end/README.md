# Application Web — Soirée Caritative 2026 (Front-End)

Application React / TypeScript / Vite pour la 1ère Soirée caritative « AU CŒUR DES COULEURS » de la Maison Ronald McDonald de Toulouse.

Pour la documentation complète du projet, veuillez consulter le [README principal à la racine](../../README.md).

---

## 🚀 Démarrage Rapide

```bash
# Installation des dépendances
npm install

# Démarrage en mode développement (HMR)
npm run dev

# Compilation pour la production
npm run build

# Prévisualisation locale du build
npm run preview
```

L'application écoute par défaut sur `http://localhost:5173`.
